# 2024년 머신러닝과 딥러닝 학습 기록

2024년 2학기 수업 과제와 실습 노트북을 보관한 저장소입니다. 교재 예제와 직접 수정한 과제를 함께 포함하며 실무 경력·독자 연구 성과로 제시하지 않습니다.

| 주제 | 포함된 자료 |
| --- | --- |
| KNN · SVM | 주차별 예제·수정·활용 노트북 |
| K means · PCA | 군집화와 차원 축소 실습 |
| MNIST · Fashion MNIST | 이미지 데이터 학습 과제 |
| 전이학습 | 10주차 과제 노트북 |

파일명에 책·수정·활용을 구분한 원본 이름을 유지했습니다. 저장소 정리에서는 노트북을 새로 실행하거나 정확도를 재측정하지 않았습니다. 면접에서는 직접 설명 가능한 노트북과 수정 내용을 골라 소개합니다.

대표 서비스 프로젝트는 [프로필](https://github.com/thdnjs0730)에서 확인할 수 있습니다.
